English — Queue Manager features

Create 10–500 repeated prompts, paste tasks or import TXT, edit and search drafts, reorder one or many messages by drag-and-drop, then explicitly send to the native OpenCode queue. Inspect or cancel pending messages; running tasks stay untouched.

Draft list: Repeat a prompt N times · Add to drafts · ↑ Move selected up · ↓ Move selected down · Send all to queue

Native queue: OpenCode's pending queue (running work is separate). Sort drafts before sending.

Language: Follow OpenCode

⚠ Send all to queue: Sending can start model work and incur charges. Check the messages first.

⚠ Cancel all pending: Only pending messages will be canceled; running work continues.
