Review before you queue

Batch prompts

10, 25, 50, 100, 200 or a custom count. Import line-separated TXT files as staged messages.

Edit & order

Search, select, edit, duplicate, delete, sort and rearrange drafts before sending.

Native queue

Send prompts to OpenCode’s native inbox and cancel pending items that have not started.

Install / uninstall

Manage the plugin with the OpenCode CLI or the optional v0.3 source installer with safe config backups.

Install from npm

OpenCode v2 has a built-in plugin manager. Install the latest published release with:

opencode plugin add @bybrawe/opencode-queue-manager

After installation, restart OpenCode and look for the Queue Manager command (/qm). The installer is available on npm, and the verified GitHub Actions release workflow publishes future package updates automatically.

Model provider independent

Use your existing OpenCode-selected model, including supported DeepSeek, OpenAI, or Anthropic models. This is not a separate DeepSeek application plugin.

Experimental: actual OpenCode Desktop compatibility remains unverified. Large message queues may incur model charges. Sorting and editing apply to drafts, not to already-running prompts.
