# Queue Manager — 20-language feature guide

**OpenCode v2 Desktop GUI** supports 20 languages. Choose the language dropdown inside the Queue Manager panel, or select **Auto** to follow OpenCode's interface language. The choice is saved globally. Arabic and Persian use right-to-left layout. Plugin command labels follow the host interface language; the manual selector changes the Queue Manager panel. The TUI's separate interface is not claimed to be fully localized.

Core features, safety warnings and major controls are translated below. Some low-frequency diagnostics fall back to English. These community translations are open to corrections via pull requests.

**Install or update:** `opencode plugin update @bybrawe/opencode-queue-manager` · **Open:** `/qm` · [npm package](https://www.npmjs.com/package/@bybrawe/opencode-queue-manager) · [Web language guide](https://bybrawe.github.io/OpenCode-Queue-Manager/languages.html)

**Draft list:** Repeat a prompt N times; Add to drafts; Select all; ↑ Move selected up; ↓ Move selected down; Send all to queue.

**Language:** Follow OpenCode

**⚠️ Send all to queue:** Sending can start model work and incur charges. Check the messages first.
